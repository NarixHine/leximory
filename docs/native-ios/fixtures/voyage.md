# Le temps de regarder

On peut voyager sans aller loin. Il suffit parfois de {{ralentir||ralentir||Aller moins vite.}} et de regarder la rue que l'on connaît déjà.

## Un carnet ouvert

Un mot nouveau, une lumière différente, une conversation inattendue. Le carnet garde ces petites découvertes.

Lire, c'est aussi prendre le temps de regarder.
