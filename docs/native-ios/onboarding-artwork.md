# Onboarding artwork

`leximory-icon.png`, `lawn.png`, `lawn-night.png`, and `cat.png` reuse the canonical web assets from `apps/leximory/public`. The lawn and sprite WebP containers were converted to PNG without redrawing their content.

`lawn-portrait.png` is a generated portrait adaptation of the canonical daytime watercolor lawn, created with the image-generation skill at the user's request. It has a transparent background and approximately 4:5 proportions. iPhone displays it with aspect fit; iPad retains the original wide lawn. Native word pills and the original cat sprite are independent overlays.
