# Leximory native design direction

The maintained specification is [DESIGN.md](../../apps/leximory-ios/DESIGN.md). It defines the canonical web colors, bundled font roles, card spacing, native Liquid Glass navigation, wrapping reader headers, annotation trays, and ebook behavior for iPhone, iPad, and Mac Catalyst.

The web app remains canonical. Inspect its signed-in interface and source when a layout or action is uncertain. The earlier Family-style custom tab bar has been replaced by native navigation at the user's request.

Onboarding retains the original cat icon, wordmark with built-in small caps, gradient AI accent, original Chinese copy, watercolor lawn, word pills, and directional cat movement. Do not introduce alternate marketing copy.

Current test evidence and remaining device/distribution gates are in [verification.md](verification.md).
